= SBOM Generation

Since v0.9 the generation of an SBOM (https://snyk.io/de/learn/software-bill-of-materials/[Software Bill Of Materials]) is supported.
It uses the https://github.com/CycloneDX/cyclonedx-maven-plugin[CycloneDX Maven Plugin] to generate a link:../../../target/bom.json[bom.json] and link:../../../target/bom.xml[bom.xml] file in the target directory:

[source]
----
$ mvn package
----


== Vulnerabilities

To scan the SBOM for known vulnerabilities you can use https://github.com/anchore/grype[grype]:

[source]
----
$ cd target
$ grype sbom:bom.json
----
